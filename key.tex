
\section*{Key}

\begin{itemize}
    \begin{itemize}
      \item VALOR namespaces: valor::utils
      \item External packages: e.g. ROOT, GSL
      \item Object names and function arguments: e.g. {\color{amber}covariance\_matrix}
      \item External class names: e.g. {\color{cadmiumgreen} TLorentzVector}
      \item VALOR class names: e.g. {\color{cadmiumgreen} \bf FitModelABC}
      \item VALOR application names: e.g. {\it valor-adaptive\_mcmc}
      \item VALOR library names: e.g. {\it libValorOsc}
      \item Filenames and paths (in single quotes): e.g. {\it`/data/flux/bnb.root’}
      \item URLs: e.g. {\color{blue} http://valor.pp.rl.ac.uk}
      \item String literals (in double quotes): e.g. {\it “G16\_02a\_01\_000”}
      \item Function signatures: e.g. {\it \color{cadmiumred} const Registry \& Metadata(void) const}
      \item Typed-in commands: e.g. {\bf \tt \% gevdump -f /data/file.ghep.root}
      \item Fragments of above (in single quotes): eg. {\bf \tt ‘-n 100’}
      \item Environmental variables: e.g. {\bf \tt \$VALOR\_SDK}
    \end{itemize}
\end{itemize}

Note: A leading \% in typed-in commands represents a shell prompt.
